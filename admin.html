Set ADMIN_GEMINI_API_KEY for admin Gemini and scan OCR. Set ADMIN_CLOUDFLARE_ACCOUNT_ID and ADMIN_CLOUDFLARE_API_TOKEN for Cloudflare Workers AI text processing.             AI PROVIDERS
    Student AI connection status
    
            
    These keys serve the student AI interface. The test below is an explicit student-service diagnostic and consumes a small amount of that service’s quota. Admin document processing uses separate keys in Upload documents → Counsel Working Station.
    
            
    Sign in as an administrator to load the status.
    
            
    
            
    
            
    
            
    To add or change a key: open dashboard.render.com → the web service this site runs on (fire-counsel-2) → Environment → add at least one writer key: GEMINI_API_KEY (from aistudio.google.com/apikey), GROQ_API_KEY (from console.groq.com/keys, starts with gsk_), DEEPSEEK_API_KEY (from DeepSeek API keys), or OPENROUTER_API_KEY (from openrouter.ai/keys) and a search key: TAVILY_API_KEY (from app.tavily.com; key prefixes can vary) or BRAVE_SEARCH_API_KEY (from Brave Search API). You can also use SERPAPI_API_KEY from SerpAPI. Multiple search keys enable failover; unused providers are optional. DeepSeek API usage is billed; free search/AI plans have limits. Any configured fallback may consume its own quota or credit. Set AI_WRITER_PROVIDER_ORDER=groq,deepseek,gemini,openrouter to prefer Groq and WEB_SEARCH_PROVIDER_ORDER=tavily,brave,serpapi,gemini for retrieval. Keys need the provider's active API access/quota; installing the Brave browser is not enough. Then → Save and deploy. If using an environment group, link it to this exact service and remove any blank/stale service-level overrides for these names. Confirm that the deployment becomes Live; saving keys on another service or only in GitHub does not configure this API.
